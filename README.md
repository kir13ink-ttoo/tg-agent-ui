# tg-agent-ui

Telegram Mini App для утреннего дайджеста: погода, курсы валют и задачи на день
в одном нативном экране. Serverless — вся статика живёт здесь, данные приходят
из URL hash.

**Live:** https://kir13ink-ttoo.github.io/tg-agent-ui/

## Возможности

- 📱 Telegram Web App API: `ready()` + `expand()`, автоматическая тема через
  CSS-переменные `--tg-theme-*` (light/dark).
- 🌤 Погода в Сием-Рипе.
- 💱 Курсы USD/RUB, USD/KHR и USDT.
- 📋 Напоминания/задачи на сегодня.
- 🔒 Данные не уходят на сервер: payload находится во фрагменте URL (`#…`),
  который браузер не передаёт в HTTP-запрос.

## Как передаются данные

Бэкенд собирает JSON, кодирует его в **URL-safe Base64 без padding** и открывает:

```text
https://kir13ink-ttoo.github.io/tg-agent-ui/#data=<base64url>
```

Фронтенд:

1. читает `window.location.hash`;
2. отрезает префикс `data=`;
3. меняет `-`/`_` обратно на `+`/`/`;
4. восстанавливает padding: `'='.repeat((4 - len % 4) % 4)`;
5. декодирует через `atob()` + `TextDecoder('utf-8')` и рендерит блоки.

Пример payload:

```json
{
  "generated_at": "2026-11-11T13:10+00:00",
  "weather": { "city": "Siem Reap", "text": "🌤 +31°C, влажность 70%" },
  "rates": { "fiat": "USD/RUB: 80.5", "usdt": "USDT/USD: 1.0" },
  "tasks": [{ "time": "2026-11-11T09:00:00+00:00", "text": "Позвонить Алексу" }]
}
```

Без параметра `#data=…` страница показывает аккуратное сообщение с просьбой
открыть дайджест из бота.

## Локальный запуск

```bash
cd tg-agent-ui
python3 -m http.server 8080
```

Откройте <http://localhost:8080/> — без данных увидите заглушку. Чтобы проверить
рендер, сформируйте ссылку с `#data=` (например, скриптом бэкенда).

## Деплой

GitHub Pages: **Settings → Pages → Deploy from a branch → `master` / `(root)`**.
Файл `.nojekyll` уже добавлен, чтобы Pages не фильтровал файлы с `_`.

Любой коммит в `master` автоматически обновляет страницу.

## Связанное

Исторически страницу открывал приватный бот `tg-agent` (aiogram) кнопкой
«📊 Открыть дайджест». Сейчас бот перешёл на нативные Telegram HTML-виджеты
(`sendWidget`), поэтому этот Mini App больше не используется ботом, но остаётся
доступным как standalone-версия дайджеста.
